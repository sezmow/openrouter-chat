Capabilities
Provider
Runs entirely in your browser. Calls OpenRouter directly, and NVIDIA through your configured proxy. Keys are stored only in this browser's local storage.

API keys & settings

Add a key for at least one provider to start chatting. Both are optional — add either, or both.

OpenRouter
Get a key at openrouter.ai/keys. Calls go straight from your browser to openrouter.ai.
NVIDIA
Get a key at build.nvidia.com. NVIDIA's API has no CORS support, so browser requests need a small relay — see nvidia-proxy-worker.js in the repo and the README for the one-time Cloudflare Worker setup. Your key is sent through the proxy on each request only; it's never stored there.
Keys are saved only in this browser's localStorage.
